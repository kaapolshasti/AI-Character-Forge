# Ennui Character References

Store approved character reference images in this directory.

## Recommended References

- Front-facing portrait
- Three-quarter portrait
- Side profile
- Full-body front view
- Full-body side view
- Back view
- Alternate facial expressions
- Outfit details

## Consistency Guidelines

Keep the character's defining facial structure, blue eyes, black hair,
and established design consistent across reference images.

Only include images that you have permission to publish.
