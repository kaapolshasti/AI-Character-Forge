# Ennui — Original Character

Ennui is an original character developed for anime-inspired storytelling
and AI-assisted character creation.

## Character Overview

- Character name: Ennui
- Character type: Japanese samurai
- Style: Anime / dark fantasy
- Gender: Male
- Hair: Jet-black, traditional samurai updo
- Eyes: Blue
- Build: Lean and athletic
- Outfit: Black kimono with crimson accents and gold dragon embroidery

## Project Goals

This project aims to preserve Ennui's visual identity and develop a
reusable character model for consistent image generation and storytelling.

## Repository Contents

- `references/` — Character reference images and approved designs.
- `training/` — Training settings, notes, and checkpoint information.
- `lora/` — LoRA model documentation and download information.

## Training

The character LoRA was trained using Draw Things.

The training checkpoints and final exported model will be documented
separately.

## Generation Workflows

ComfyUI workflows and generation settings will be documented as
